# Expense Tracker

A simple Flutter app to track my daily income and expenses and keep my money organized.

## About the App

I built this app to keep track of my money and understand how I spend it. It helps me record the money I receive, track my expenses, and check my transaction history whenever I need.

The app also has circular charts that show where my money is going, making it easier to understand which categories I spend the most on.

## Features

* Add and track income
* Record daily expenses
* View transaction history
* Check where my money comes from and where I spend it
* View circular charts to understand spending by category
* Keep track of income and expenses in one place

## Built With

* Flutter
* Dart

## Getting Started

Clone the repository:

```bash
git clone https://github.com/MuhammedShibilameri/expense-tracker.git
```

Go to the project folder:

```bash
cd expense-tracker
```

Install the dependencies:

```bash
flutter pub get
```

Run the app:

```bash
flutter run
```
